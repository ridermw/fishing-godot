# fishing-godot

Rebuild the fishing game from **https://github.com/ridermw/fishing** (play it at https://ridermw.github.io/fishing/) using **Godot 4 + C#**.

Make it the same game: same world, mechanics and features. Generate all art and sound in code, with no image or audio files. The Rust port at https://github.com/ridermw/fishing-rs is a second reference.

Export it for the web and deploy it to GitHub Pages from this repo.
